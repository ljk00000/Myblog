# 前台样式约定

采用普通暗色博客布局，首页直接展示最新文章和精选资源。

- 文案直接说明页面用途或当前状态，使用“文章”“资源”“暂无文章”等常用表达。
- 不添加宣传口号、装饰性英文眉题、大幅首屏、插画、光晕、渐变或鼠标跟随效果。
- 使用系统字体，正文 16px，页面标题 26–30px，列表标题 18–20px。
- 页面最大宽度 1000px，阅读正文不超过 720px；手机两侧保留 16–20px。
- 背景、表面和分隔线使用中性灰，链接和焦点使用单一蓝色。按钮和容器使用小圆角。
- 文章按普通列表展示，资源使用简洁卡片。只展示真实封面和公开数据，不补演示内容或统计。
- 不添加展示动画。保留加载提示、阅读进度、目录定位、代码复制等功能反馈，并支持减少动态效果。
- 保留搜索、筛选、分页、移动导航、键盘操作、可访问名称、可见焦点、SSR 正文和真实 404。
- 站点内容由 Java 提供；动态 SSR 和 Pages 静态快照使用相同页面，不更改接口或数据库来处理样式问题。

修改后运行类型检查与生产构建，检查桌面和手机上的空状态及有内容页面，确认无横向溢出、正文隐藏或客户端错误。
