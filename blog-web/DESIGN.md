# 公开博客设计约定

使命：让访客直接阅读真实文章、查找资源；内容和站点身份以 Java 公开接口为准。

## 视觉与交互

- 色彩：背景 #f8faf8、正文 #182b29、次级文字 #61726c、强调 #087f70、边线 #dfe8e2、错误 #a13131；白色卡片。
- 字体：原生系统无衬线字体，正文 16–18px、行高 1.8；代码使用系统等宽字体。
- 间距：4px / 8px 基准，8、16、24、32、48、64、96px；内容最大宽度 1120px，正文最大宽度 720px。
- 圆角：输入控件 8px、卡片 16px、筛选胶囊 999px；边框优先于阴影。
- 动效：交互颜色 120ms、状态出现 220ms cubic-bezier(.2,.8,.2,1)，列表微量错峰；尊重 prefers-reduced-motion。
- 可访问性：跳转正文、语义导航/表单、可见焦点、足够点击区域、原生可访问状态、移动菜单的 aria-expanded。

## Do / Don't

- 使用真实分类、标签、摘要、发布日期与归档数量；为空时说明尚未发布。
- 页面标题清楚，列表、筛选和分页保持稳定栅格；长标题及 URL 可换行。
- 正文 HTML 使用后端统一净化结果；本地交互仅增强目录、代码复制和图片排版。
- 不添加假文章、演示作者、统计、推广、营销占位图或后台样式。
- 不安装 CMS、字体服务、动效库或组件库；不永久缓存站点设置、接口或 HTML。

## 实施假设

- 界面语言为简体中文；无封面时保持纯文字卡片。
- 搜索同时查文章与资源，两个结果区独立分页。
- 详情、归档和筛选 URL 可刷新、可分享；未知详情返回实际 HTTP 404。
- 部署通过 NUXT_API_BASE 指向网关，公开规范网址由 Java 站点设置 siteUrl 提供。
