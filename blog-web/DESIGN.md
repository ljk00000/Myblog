# 公开博客设计约定

使命：为真实文字与发现提供安静、鲜明、值得停留的阅读空间。所有站点身份、文章、资源、分类与数量均来自现有 Java 公开接口。

## 视觉契约：深色极光 × 精致阅读

- 画布：午夜蓝黑 `#090b13`，表面 `#111421` / `#171a2b`，正文 `#eef0fa`，阅读正文 `#ced1e2`，次级 `#999fb8`，细线 `#ffffff12`。
- 强调：紫 `#a995ff`、玫瑰 `#f29cce`、青蓝 `#83dceb`；渐变用于品牌、主操作、选中态与抽象书页，避免大段正文渐变。错误 `#ffa9b3`，成功 `#91dfc7`。
- 字体：本机中文系统字体，无外部字体。界面 14–16px，正文 17px / 2；标题 32–76px，重量 600–750，中文标题适当收紧；等宽字体仅用于代码、索引与英文眉题。
- 尺度：4px / 8px 节奏；12、16、24、32、48、64、96px。画布宽 1200px；正文 740px；目录 220px。320px 起可阅读，所有网格使用 minmax(0, 1fr)。
- 圆角：按钮与输入 12px，卡片 20px，主视觉 32px，导航 20px；边框低对比，焦点高对比。
- 材质：低透明网格、静态颗粒、局部柔光、悬浮磨砂导航；装饰只存在于独立 aria-hidden 图层，不能承载信息或拦截点击。

## 动效与交互

- 首屏文字与书页分层入场，列表在进入视口时轻量错峰显现；SSR 与禁用 JS 时内容始终可见。
- 极光与书页低频往返变化，鼠标仅通过一个委托监听与 RAF 更新卡片光感和首屏轻微视差；不逐卡片注册事件。
- 卡片抬升、渐变边线、按钮扫光与箭头位移表达可交互状态。过渡明确限定属性；禁止 transition: all。
- prefers-reduced-motion 下停止 CSS 动画、平滑滚动、JS 视差与滚动动画监听；粗指针关闭视差。路由完成后注册新节点，卸载清理监听、observer、RAF。
- 移动菜单支持 Escape、aria-expanded、当前导航；代码复制提供成功与失败提示；目录高亮与阅读进度为真实文档增强。

## 页面规则

- 首页为双栏杂志式首屏与原生 SVG 流光书页；文章与资源均有真实入口。空列表使用不同、紧凑的编辑式留白，不用重复大空框撑版。
- 有封面时展示真实图片，无封面时采用克制的抽象线条；绝不伪造文章、数字、推荐、作者经历或身份。
- 筛选、分页、搜索、归档、关于、详情、空态、加载与错误共享视觉语言。保留原数据请求、查询参数、动态站点刷新、SEO、HTTP 404 和代理边界。
- 正文保持宽松行距；长 URL 可换行；代码和表格在自己的容器内滚动，禁止通过全局 overflow-x:hidden 隐藏布局缺陷。
- 使用语义按钮/链接、可见键盘焦点、正文跳转、足够触摸面积。所有操作必须有真实去向或结果。

## Do / Don't

- 做：让内容拥有视觉层级；保留真实摘要与元信息；复用 token 与组件；观察页面与验证构建。
- 不做：虚构内容、身份和统计；假功能控件；为装饰安装依赖；外部字体服务；修改后台、接口、鉴权或部署边界。

## 实施假设

- 简体中文界面；站点副标题直接作为首页主标题，无描述时使用说明阅读入口的中性微文案。
- 当前内容为空；空态也是正式设计的一部分。有内容时自动呈现原有真实卡片。
- 搜索仍同时查文章与资源，两个结果区独立分页；详情与筛选 URL 可刷新、可分享。
